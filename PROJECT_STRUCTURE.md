# 🏗️ SYLTRA SMART - Project Structure

## 📋 Overview
SYLTRA SMART is a comprehensive smart technology ecosystem with multiple applications, documentation, and business components.

---

## 📂 Directory Organization

### 🎯 **Core Brand & Identity**
- **`brand/`** - Brand guidelines, colors, typography, visual standards
- **`identity/`** - Identity assets, logos, brand positioning
- **`company-profile/`** - Company information, profiles, official materials

### 🏠 **Product Applications**
- **`syltra-home/`** - Main Smart Home application
- **`syltra-home-app/`** - Smart Home mobile app
- **`syltra-tv-app/`** - TV application interface
- **`website/`** - Official website (monorepo with services & apps)

### 📚 **Documentation & Concepts**
- **`syltra concept/`** - Product concepts, design thinking, strategic documents
- **`syltra system/`** - Technical system documentation, architecture
- **`iso/`** - ISO documentation and compliance materials

### 🔧 **Development**
- **`src/`** - Main source code
- **`scripts/`** - Build and utility scripts
- **`public/`** - Static assets
- **`node_modules/`** - Dependencies (npm packages)

### 📊 **Business & Assets**
- **`investment/`** - Investment materials, pitch decks, funding docs
- **`posters/`** - Marketing posters and visual materials

---

## 🎨 Key Features
- ✅ All branding unified under **SYLTRA SMART**
- ✅ Organized by functional domains
- ✅ Clear separation of concerns
- ✅ Scalable architecture
