## الطبقات

### 1) الفكرة الأساسية
سيلترا هيلث ليست لوحة تجمع بيانات، بل طبقة ذكاء صحي: تربط بيانات الجسم بحركة المنزل
وبيئته ومواقع الأشخاص الموثوقين، تتعلّم النمط الطبيعي، تهيّئ البيئة، ترصد التغيّر غير
المعتاد، تتحقق من المستخدم، ثم تصل إلى الشخص الأنسب وفق خطة يوافق عليها مسبقًا.
التفصيل الكامل في: `الوثائق/01-الفكرة-الأساسية.md`.

### 2) الموقع التسويقي (14 صفحة، عربي/إنجليزي)
- الرئيسية · كيف تعمل · للأفراد · كبار السن · الحالات المزمنة (+ ضغط الدم + السكري) ·
  النوم والتعافي · صحة المنزل · لمقدمي الرعاية · التكاملات · المدونة · الخصوصية ·
  عن الشركة · التواصل/التجربة المبكرة.
- تصميم فاتح، نبرة إنسانية، هيروهات حقيقية، تصميم تحريري (بدون كروت AI أو إم-داش).
- **المكوّنات:** مسار الاستجابة الذكية، المكوّنات الخمس، مستويات الاستجابة، الدائرة
  الموثوقة، سيناريوهات (السكري + كبار السن)، رحلة الإعداد (موافقات/دائرة/خطة/وضع اختبار).
- **الالتزام:** لا تشخيص، ليست طوارئ، لا تضمن وصول المساعدة، لا اتصال تلقائي بالإسعاف.

### 3) المدونة (11 مقالًا أصليًا، عربي/إنجليزي)
مقالات عن الصحة المتصلة، النمط الشخصي، الدائرة الموثوقة، وضع الاختبار، البيئة المتكيّفة،
والخصوصية. المسار: `/health/blog`.

### 4) لوحة الإدارة (Admin Console)
لوجن محمي + أقسام: التسجيلات (إحصائيات + جدول)، الخدمات (تفعيل/تعطيل)، الإعدادات.
مخفيّة عن التسويق و noindex.

### 5) الباك-إند (Cloudflare Worker + D1)
- قاعدة D1 `syltra-health`: جدولا `registrations` و `services`.
- Worker: تسجيل عام، لوجن أدمن (توكن HMAC 12 ساعة)، قراءة التسجيلات، إدارة الخدمات.
- الكود ودليل التشغيل في مجلد `health-api/` داخل مشروع الموقع.

## الأصول في هذا المجلد
- `الصور/الهيرو/` — 11 صورة هيرو حقيقية (لكل صفحة صورتها).
- `الشعارات/التطبيقات/` — الشعارات الرسمية (Apple Health, Google Health Connect,
  Samsung Health, Fitbit, WHOOP, HUAWEI Health, Nike Run Club).
- `الشعارات/الأيقونات/` — أيقونات + شعار سيلترا المستخرج.

## التشغيل والنشر
- **محليًا:** `cd "syltra smart" && npm run dev`
- **البناء:** `npm run build:pages` (يخرج إلى `out/`)
- **النشر:** كل `git push origin main` يعيد نشر مشروعي Pages تلقائيًا.
- **الباك-إند:** `cd health-api && npm run deploy` (التفاصيل في `health-api/README.md`).
